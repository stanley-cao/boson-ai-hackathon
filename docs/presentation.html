P PolyglotWhat the model does

The model listens, adapts, teaches and remembers.

Listen

Understands speech

Processes the learner’s original audio and transcribes each turn.

Adapt

Follows the learner

Responds to language switches, level changes, pauses and interruptions.

Teach

Finds teachable moments

Calls tools for corrections, phrases, pronunciation and speaking pace.

Remember

Builds study material

Turns the conversation into cards that can be reviewed and replayed.

P PolyglotAppendix · Product Q&A

Why not a normal voice chatbot?

Polyglot turns moments into structured, persistent corrections, phrases and pronunciation cards.

Does it support every language?

No. It supports six targets today and uses profiles so responsible expansion is straightforward.

Is pronunciation objectively scored?

It is qualitative realtime guidance, not yet a dedicated phoneme-level scoring system.

Where is progress stored?

Versioned local browser storage today; accounts and cloud sync are next-stage product work.

Who is it for?

English-speaking beginners and intermediate learners who need low-pressure speaking practice.

What is the business path?

Consumer practice subscriptions, then teacher dashboards and institutional language programs.

P PolyglotAppendix · Technical Q&A

Why Higgs?

One realtime session combines original audio understanding, conversation, streaming speech and tool calling.

How is the API key protected?

The server mints ten-minute ephemeral keys; the permanent key never enters the browser.

How do interruptions work?

Playback counts heard samples, flushes queued audio and truncates model history to the audible point.

How are duplicates prevented?

Tool calls are deduplicated by call ID and one continuation is sent after the complete batch.

Why the 1.5-second pause?

Learners hesitate. The extra window reduces accidental turn splitting at the cost of modest latency.

How does avatar mode differ?

A Python agent owns the session in LiveKit and forwards tool calls to the same browser handlers over RPC.

A2
If asked about consistency: TypeScript exports prompts and schemas as JSON for the Python agent, so both modes use the same tutor contract.
