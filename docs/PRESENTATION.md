# Polyglot presentation deck

Open `docs/presentation.html` in a browser. It is self-contained and does not
need the development server or an internet connection.

## Controls

- Right arrow, Page Down, or Space: next slide
- Left arrow or Page Up: previous slide
- Home / End: first / last slide
- `N`: toggle speaker notes
- Swipe horizontally on a touch screen

The timed presentation is slides 1–10. Slides A1–A3 are backup slides for
questions and demo recovery.

## Before presenting

1. Replace `Your team names` on the title slide.
2. Rehearse the live-demo prompts on slide A3.
3. Use voice-only mode for the primary demo and keep avatar mode optional.
4. Clear old study notes before recording or presenting.
5. Keep a screen recording of the successful demo as a fallback.

## Export to PDF

Open the deck in Chrome or Safari, choose **Print**, select **Save as PDF**, and
enable background graphics. The print stylesheet exports one 16:9 slide per
page and hides navigation controls and speaker notes.
